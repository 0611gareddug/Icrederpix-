# 🎮 트랩빌더즈 (Trap Builders) 기획서 v1.0

> 장르: 2D 픽셀아트 파티 플랫포머 (함정 배치와 레이스)
> 플랫폼: 웹 브라우저 (PC와 모바일), GitHub Pages 배포
> 인원: 1~6명 (AI 봇과 온라인 혼합)

---

## 1. 게임 한 줄 소개

**"함정을 깔아라, 그리고 네가 깐 함정을 피해 골인하라!"**
매 라운드 플레이어들은 상자에서 함정이나 블록을 하나씩 골라 맵에 배치하고, 다 함께 출발점에서 골까지 달려요.
맵은 라운드가 지날수록 점점 험해지고, **맵이 너무 쉬워서 전원이 골인하면 아무도 점수를 못 받기 때문에**, 모두가 "나만 통과할 수 있는" 함정을 노리는 긴장감이 핵심이에요.

---

## 2. 핵심 게임 루프

한 판(매치)은 여러 라운드로 이루어지고, 한 라운드는 4단계로 진행돼요.

| 단계 | 제한 시간 | 내용 |
|---|---|---|
| ① 파티 상자 | 15초 | 화면 중앙에 상자가 열리고 아이템 (인원수 + 2)개가 나와요. 무작위 순서로 한 명씩 하나를 골라요. 시간이 지나면 남은 것 중에서 자동으로 골라져요. |
| ② 배치 | 20초 | 고른 아이템을 맵의 원하는 칸에 놓아요. 회전할 수 있고, 다른 플레이어가 무엇을 어디에 놓는지 실시간으로 보여요. 시간 안에 놓지 않으면 아이템은 사라져요. |
| ③ 달리기 | 최대 60초 | 모두 동시에 출발해요. 한 번 죽으면 그 라운드는 끝이고 관전 모드로 바뀌어요. 시간이 끝나면 남은 사람은 실패 처리돼요. |
| ④ 결과 | 5초 | 점수 막대가 차오르는 연출과 함께 이번 라운드 득점을 보여 줘요. |

- 라운드 1회는 대략 **1분 20초~1분 30초** 걸려요.
- 누군가 목표 점수에 도달하면 즉시 매치가 끝나고 우승 연출이 나와요.
- **라운드 상한**에 도달하면 가장 점수가 높은 사람이 우승해요. 동점이면 연장 라운드 1회를 진행하고, 그래도 동점이면 공동 우승이에요.

### 2-1. 판 길이 (방장이 선택)
| 설정 | 목표 점수 | 라운드 상한 | 예상 시간 |
|---|---|---|---|
| 짧게 | 15점 | 6라운드 | 약 6분 |
| 보통 | 30점 | 12라운드 | 약 12분 |
| 길게 | 45점 | 18라운드 | 약 18분 |

## 3. 점수 규칙

| 항목 | 점수 | 조건 |
|---|---|---|
| 골인 | **+5점** | 제한 시간 안에 골 깃발에 닿음 |
| 함정 처치 보너스 | **+2점** (1명당) | 내가 배치한 함정에 다른 플레이어가 죽음. 자기 함정에 자기가 죽으면 보너스 없음. |
| 처치 보너스 조건 | 제한 없음 | 본인의 골인 여부와 상관없이 처치할 때마다 받아요. |
| 전원 골인 | **전원 0점** | 맵이 너무 쉬웠다는 뜻이에요. 화면에 "너무 쉬워요!" 표시가 나와요. |
| 전원 실패 | 골인 점수 없음, **처치 보너스는 그대로 인정** | 어려운 맵도 깰 수 있으니 별도 벌칙은 없어요. 화면에 "아무도 못 갔어요!" 표시만 나와요. |

- 혼자 남아서 플레이 중일 때(나머지 모두 탈락)는 화면 위쪽에 **"마지막 생존자!"** 배너가 떠서 긴장감을 줘요.
- **처치 판정**: 플레이어가 함정에 닿아 죽으면, 그 함정을 배치한 사람에게 처치가 기록돼요. 폭탄 폭발이나 화살처럼 간접적으로 죽는 경우에도 발사한 함정의 주인에게 기록돼요.

## 4. 조작과 이동

### 4-1. 기본 물리 수치 (1칸 = 16픽셀 기준)
| 항목 | 수치 | 설명 |
|---|---|---|
| 걷기 최고 속도 | 초당 6칸 | 가속 0.08초, 감속 0.06초 |
| 점프 최고 높이 | 3.5칸 | 버튼을 오래 누를 때 |
| 점프 최저 높이 | 1.2칸 | 버튼을 짧게 누를 때 (점프 높이 조절) |
| 코요테 타임 | 0.1초 | 발판에서 떨어진 직후에도 점프를 받아 줘요 |
| 점프 입력 버퍼 | 0.1초 | 착지 직전에 누른 점프도 인정해요 |
| 최대 낙하 속도 | 초당 18칸 | |

### 4-2. 이동 기술
| 기술 | 동작 | 세부 |
|---|---|---|
| 벽 점프 | 공중에서 벽에 붙으면 천천히 미끄러지고, 점프하면 반대 방향으로 튀어 나가요 | 벽 미끄러짐 속도 초당 3칸, 튀어 나간 뒤 0.15초 동안은 방향 입력이 약하게 먹혀서 같은 벽을 바로 다시 못 타요 |
| 점프 높이 조절 | 점프 버튼을 떼는 순간 상승이 끊겨요 | 정밀한 짧은 점프가 가능해요 |
| 대시 | 바라보는 방향(또는 입력 방향 8방향)으로 짧게 돌진해요 | 거리 3칸, 0.15초, 공중에서는 착지 전까지 1회, 쿨타임 0.6초, 대시 중에는 중력 무시 |
| 웅크리기 | 몸 높이가 절반이 돼요 | 1칸 높이 통로를 지날 수 있어요. 이동 속도 50%. 달리다가 웅크리면 0.4초 동안 미끄러지는 **슬라이딩**이 나가요 |

### 4-3. 키 배치
| 동작 | PC | 모바일 |
|---|---|---|
| 이동 | A/D 또는 ←/→ | 왼쪽 가상 조이스틱 |
| 점프 | 스페이스 / W / ↑ | 오른쪽 큰 버튼 (A) |
| 대시 | Shift / K | 오른쪽 작은 버튼 (B) |
| 웅크리기 | S / ↓ | 조이스틱을 아래로 |
| 배치 회전 | R / 마우스 휠 | 회전 버튼 |
| 배치 확정 | 클릭 / 엔터 | 확정 버튼 |
| 일시정지/메뉴 | Esc | 우상단 메뉴 버튼 |

- 게임패드(엑스박스/플스 패드)도 자동 인식해요.
- 설정에서 키를 바꿀 수 있어요.

## 5. 함정·블록 목록 (29종)

공통 규칙
- 맵은 격자(칸) 단위로 배치하고, **출발 지점과 골 주변 2칸**에는 배치할 수 없어요. (배치 불가 칸은 빨간 빗금으로 표시돼요.)
- 이미 무언가 있는 칸에는 겹쳐 놓을 수 없어요. 단, **폭탄**은 예외예요.
- 모든 움직이는 함정은 **라운드 시작 시각을 기준으로 정해진 주기**로 움직여서 모든 플레이어에게 똑같이 보여요.

### 5-1. 지형 블록 (길을 만들어 줘요)
| # | 이름 | 크기 | 동작 |
|---|---|---|---|
| 1 | 나무 블록 | 1×1 | 평범한 발판이에요 |
| 2 | 긴 발판 | 3×1 | 위에서만 밟을 수 있고 아래에서는 통과해요 |
| 3 | 사다리 | 1×3 | 위/아래 입력으로 오르내려요 |
| 4 | 트램펄린 | 1×1 | 밟으면 5칸 높이로 튕겨 올라가요. 회전하면 옆으로 튕겨요 |
| 5 | 움직이는 발판 | 2×1 | 4칸 거리를 2초 주기로 왕복해요. 위에 탄 플레이어도 함께 움직여요 |
| 6 | 컨베이어 | 3×1 | 위에 서 있으면 초당 3칸씩 한쪽으로 밀어요 |

### 5-2. 방해 블록 (죽이지는 않지만 방해해요)
| # | 이름 | 크기 | 동작 |
|---|---|---|---|
| 8 | 얼음 블록 | 1×1 | 위에서 미끄러져서 멈추기 어려워요 (감속 1/5) |
| 9 | 끈끈이 블록 | 1×1 | 위에서는 속도 40%, 점프 높이 50%, 벽 점프 불가 |
| 10 | 무너지는 발판 | 1×1 | 밟고 0.5초 뒤 무너지고, 3초 뒤 다시 생겨요 |
| 11 | 블랙홀 | 1×1 (영향 범위 반지름 3칸) | 주변 플레이어를 중심 쪽으로 끌어당겨요. 중심에 닿으면 죽어요 (처치 판정 있음) |

### 5-3. 치명 함정 (닿으면 죽어요)
| # | 이름 | 크기 | 동작 |
|---|---|---|---|
| 12 | 가시 | 1×1 | 뾰족한 방향(회전 가능)에서 닿으면 죽어요 |
| 13 | 톱날 | 1×1 | 제자리에서 회전해요. 어느 방향이든 닿으면 죽어요 |
| 14 | 화살 발사기 | 1×1 | 2초마다 바라보는 방향으로 화살을 쏴요. 화살은 벽에 꽂히면 사라져요 |
| 15 | 화염 분사기 | 1×1 (불꽃 3칸) | 1.5초 켜짐, 1.5초 꺼짐을 반복해요. 켜지기 0.6초 전에 연기가 나서 예고해요 |
| 16 | 회전 철퇴 | 1×1 (사슬 반지름 약 2칸) | 쇠공이 원을 그리며 4초에 한 바퀴 돌아요 |
| 17 | 레이저 | 1×1 (빔은 최대 20칸) | 2초 꺼짐, 0.8초 조준(가는 선), 0.9초 발사를 반복해요 |
| 18 | 폭탄 | 1×1 | **배치하는 순간 폭발**해서 주변 반지름 2칸의 블록과 함정을 지워요. 맵이 너무 막혔을 때 길을 여는 용도예요. 출발/골 블록은 지워지지 않아요 |

### 5-4. 파티 상자 출현 규칙
- 29종 중 무작위로 (인원수 + 2)개가 나오고, 같은 아이템은 최대 2개까지 나와요.
- **폭탄은 3라운드부터** 나오고, 맵에 놓인 함정이 많을수록 나올 확률이 올라가요.
- 치명 함정만 잔뜩 나오지 않도록, 상자마다 **지형 블록이 최소 1개** 들어 있어요.

### 5-6. v1.2 밸런스 조정
- 블랙홀: 끌어당기는 범위 4칸 → 3칸, 힘 약 20% 감소
- 회전 철퇴: 반지름 2.5칸 → 약 2칸, 회전 3초 → 4초
- 레이저: 조준 예고 0.5초 → 0.8초, 사거리 최대 20칸
- 화염 분사기: 예고 0.4초 → 0.6초
- 화살 발사기: 발사 0.3초 전 발사구가 깜빡여요

## 6. 맵 (4종)

모든 맵은 가로 72칸 × 세로 20칸 크기예요. 출발 지점은 왼쪽, 골 깃발은 오른쪽에 있고, 중간에 **기본 지형**(낭떠러지, 벽, 발판)이 미리 만들어져 있어요. 기본 지형만으로는 골까지 갈 수 없거나 아주 아슬아슬하게 갈 수 있도록 설계해서, 플레이어가 놓은 블록이 길을 만들어 가게 해요.

| 맵 | 분위기 | 지형 특징 | 맵 고유 기믹 | 배경음악 |
|---|---|---|---|---|
| 🌿 초원 언덕 | 밝은 하늘, 구름, 풀숲 | 완만한 언덕과 넓은 구덩이 | 없음 (입문용) | 경쾌한 장조 칩튠 |
| ❄️ 얼음 동굴 | 푸른 결정, 고드름 | 좁은 통로, 천장이 낮은 구간 | 바닥 일부가 얼음, 천장에서 고드름이 가끔 떨어짐 (처치 판정 없음) | 신비로운 아르페지오 |
| 🔥 용암 성 | 붉은 벽돌, 용암 빛 | 아래쪽이 전부 용암, 세로로 높은 구조 | 용암이 10초마다 1칸 올라왔다가 내려가요 | 긴박한 단조 행진곡 |
| ☁️ 하늘 섬 | 노을, 떠 있는 섬들 | 섬과 섬 사이가 멀고 아래는 낭떠러지 | 5초마다 바람이 불어 한쪽으로 밀어요 (예고 화살표 표시) | 몽환적인 느린 템포 |

- 방장이 맵을 고르거나 **"무작위"**를 고를 수 있어요.
- 배경은 **시차 스크롤(패럴랙스)** 3겹으로 깊이감을 줘요.

## 7. 캐릭터와 꾸미기

### 7-1. 기본 캐릭터
- 16×16 픽셀의 **네모난 블록 몸통 캐릭터**예요. 큰 눈과 작은 팔다리가 특징이에요.
- 애니메이션: 대기(숨쉬기), 걷기 4프레임, 점프, 낙하, 벽 미끄러짐, 대시(잔상 효과), 웅크리기, 슬라이딩, 사망(픽셀이 흩어지는 연출), 골인(만세), 우승 춤.
- 모든 캐릭터의 능력은 같아요. **외형만 달라요.**

### 7-2. 꾸미기 항목
| 종류 | 개수 | 예시 | 가격 |
|---|---|---|---|
| 몸 색상 | 16 | 빨강, 주황, 민트, 보라, 무지개(움직이는 색) 등 | 기본 6개 무료, 나머지 50~300코인 |
| 모자 | 12 | 야구모자, 왕관, 개구리 모자, 우주 헬멧, 해적 모자 등 | 100~500코인 |
| 표정 | 8 | 기본, 웃음, 화남, 졸림, 선글라스 등 | 기본 2개 무료, 나머지 80~200코인 |
| 뒤 장식 | 6 | 망토, 날개, 꼬리, 배낭 등 | 200~600코인 |
| 골인 효과 | 5 | 폭죽, 하트, 별, 번개, 왕관 비 | 300~800코인 |

- 온라인에서는 **다른 플레이어에게도 내 꾸미기가 보여요.**
- 같은 방에서 몸 색이 겹치면 자동으로 테두리 색을 다르게 해서 구분해요.

### 7-3. 코인 획득
| 조건 | 코인 |
|---|---|
| 매치 1판 완료 | +10 |
| 라운드 골인 1회 | +5 |
| 함정 처치 1회 | +2 |
| 매치 우승 | +30 |
| 하루 첫 판 | +20 |

- 코인과 꾸미기는 **브라우저(기기)에 저장**돼요. 다른 기기와 연동되지 않는다는 안내 문구를 상점에 표시해요.

## 8. AI 봇

### 8-1. 달리기 인공지능
- 맵을 칸 단위로 분석해서 **"갈 수 있는 길" 지도(걷기, 점프, 벽 점프, 대시 연결)**를 만들고, 골까지 가는 경로를 찾아 따라가요.
- 움직이는 함정은 주기를 계산해서 **안전한 타이밍을 기다렸다가** 지나가요.

| 난이도 | 반응 지연 | 실수 확률 | 타이밍 판단 | 함정 배치 성향 |
|---|---|---|---|---|
| 쉬움 | 0.35초 | 높음 (점프 거리 오차 큼) | 함정 주기를 가끔 무시 | 무작위에 가까움 |
| 보통 | 0.2초 | 보통 | 대부분 기다림 | 플레이어 경로 근처에 놓음 |
| 어려움 | 0.08초 | 낮음 | 항상 최적 타이밍 | 사람들이 많이 지나간 길목을 노림. 맵이 너무 어려우면 길을 만들어 줌 |

### 8-2. 배치 인공지능
- 이전 라운드에서 플레이어들이 지나간 경로를 기억해서, **경로 위나 착지 지점**에 함정을 놓으려고 해요.
- 지난 라운드에 전원 실패했다면 지형 블록을 우선 골라서 **길을 열어 주는** 쪽으로 판단해요. (게임이 막히지 않도록)

## 9. 온라인 대전 (PeerJS P2P)

### 9-1. 방 만들기와 참가
- **방 만들기**: 5자리 영문/숫자 방 코드가 생성돼요 (예: `K7Q2M`). 헷갈리는 글자(0, O, 1, I)는 제외해요.
- **초대 링크 복사** 버튼: `…/?room=K7Q2M` 형태의 링크를 복사해요. 링크로 들어오면 바로 참가 화면이 떠요.
- **참가하기**: 방 코드를 입력하거나 링크로 들어와요.
- 방장은 빈자리에 **봇 추가/삭제**를 할 수 있어요.

### 9-2. 대기실(로비)
- 참가자 목록 (닉네임, 꾸미기 미리보기, 준비 상태, 핑 표시)
- 방장 설정: 맵, 판 길이, 봇 수와 난이도
- 모두 준비되면 방장이 시작 버튼을 눌러요.
- 간단한 **이모티콘 반응**(👍 😂 😱 😡 ❤️ GG)을 쓸 수 있어요. 자유 채팅은 넣지 않아요. (모바일 입력 불편, 비매너 방지)

### 9-3. 통신 구조
- **방장 기기가 호스트**가 되어 파티 상자, 배치, 점수, 라운드 진행을 결정해요.
- 각자의 캐릭터 움직임은 **자기 기기에서 계산**하고 초당 20번 위치를 보내요. 다른 플레이어는 0.1초 지연 보간으로 부드럽게 보여요.
- 함정은 모두 같은 시작 시각 기준으로 움직이므로 따로 동기화하지 않아도 똑같이 보여요.
- 죽음과 골인은 본인 기기가 판정해서 호스트에 알려요.

### 9-4. 연결 문제 처리
| 상황 | 처리 |
|---|---|
| 참가자가 나감 | 그 자리를 같은 꾸미기의 봇이 이어받아요 (방장 설정으로 끌 수 있음) |
| 방장이 나감 | 방이 끝나고 "방장이 나갔어요" 안내 후 메인 화면으로 돌아가요 |
| 연결 지연이 큼 | 핑이 300ms를 넘으면 해당 플레이어 옆에 노란 신호 아이콘을 표시해요 |
| 연결 실패 | 일부 회사·학교 네트워크에서는 P2P 연결이 막힐 수 있어서, "네트워크 환경 때문에 연결할 수 없어요" 안내를 띄워요 |

- 닉네임: 2~10자, 한글/영문/숫자. 기본 금칙어 필터를 넣어요.

## 10. 화면 구성

### 10-1. 화면 흐름
```
로딩 → 타이틀 → 메인 메뉴
                ├─ 혼자 하기 → 설정(맵/길이/봇) → 게임
                ├─ 방 만들기 → 로비 → 게임
                ├─ 방 참가 → 코드 입력 → 로비 → 게임
                ├─ 꾸미기 상점
                ├─ 설정
                └─ 조작법 안내
게임 → 매치 결과 → 로비(온라인) 또는 메인 메뉴(혼자)
```

### 10-2. 화면별 내용
- **로딩**: 픽셀 캐릭터가 달리는 진행 바.
- **타이틀**: 큰 픽셀 로고 "TRAP BUILDERS / 트랩빌더즈", 배경에서 봇들이 함정 맵을 자동으로 달리는 데모 화면, "화면을 눌러 시작".
- **메인 메뉴**: 왼쪽에 내 캐릭터가 크게 서 있고, 오른쪽에 큰 버튼 5개. 위쪽에 코인 표시.
- **꾸미기 상점**: 탭(색상/모자/표정/뒤 장식/골인 효과), 격자형 아이템 목록, 선택하면 캐릭터 미리보기가 바로 바뀜, 잠긴 아이템은 자물쇠와 가격.
- **설정**: 배경음악/효과음 볼륨, 화면 흔들림 켜기/끄기, 키 설정, 조작 버튼 크기(모바일), 닉네임 변경, 언어(한국어 기본).
- **게임 HUD**
  - 위쪽 중앙: 단계 이름과 남은 시간
  - 위쪽 왼쪽: 플레이어별 미니 점수 막대
  - 아래쪽: 모바일 조작 버튼
  - 달리기 중 탈락하면 "관전 중: (닉네임)" 표시, 좌우로 관전 대상 바꾸기
- **배치 단계 화면**: 카메라가 맵 전체를 보도록 줌아웃되고, 내 아이템이 손가락/마우스를 따라다니며 놓을 수 있는 칸은 초록, 불가능한 칸은 빨강으로 표시. 다른 플레이어의 커서도 색깔별로 보여요.
- **라운드 결과**: 플레이어별 가로 점수 막대, 이번 라운드에 얻은 점수가 색깔별 조각(골인 = 노랑, 처치 = 빨강)으로 쌓이는 애니메이션. 목표 점수 선이 표시돼요.
- **매치 결과**: 1~3위 시상대, 우승자 춤 애니메이션, 획득 코인, "다시 하기" 버튼.

## 11. 아트·디자인 가이드

- **내부 해상도**: 480×270 픽셀(16:9)로 그리고, 화면 크기에 맞게 **정수배로 확대**해서 픽셀이 뭉개지지 않게 해요. 화면 비율이 다르면 남는 공간은 맵 배경색으로 채워요.
- **타일 크기**: 16×16 픽셀.
- **색상 팔레트**: 32색 고정 팔레트를 써서 전체 톤을 통일해요. 맵마다 배경 색감이 다르게 보이도록 팔레트 안에서 조합해요.
- **글꼴**: 한글 픽셀 글꼴 **갈무리(Galmuri)** 사용 (무료 공개 라이선스 OFL).
- **UI 스타일**: 두꺼운 픽셀 테두리의 버튼, 누르면 2픽셀 아래로 눌리는 효과, 선택한 버튼은 흰 테두리가 깜빡여요.
- **연출 효과**: 착지 먼지, 대시 잔상, 사망 시 픽셀 파편, 폭탄 폭발 시 화면 흔들림(설정에서 끌 수 있음), 골인 시 폭죽, 함정 처치 시 처치한 사람 머리 위에 "+3" 표시.
- 모든 그림은 **코드로 직접 생성한 픽셀 스프라이트**라 외부 이미지 저작권 걱정이 없어요.

## 13. 모바일 대응

- 화면은 **가로 모드 전용**이에요. 세로로 들면 "가로로 돌려 주세요" 안내가 떠요.
- 메인 화면과 게임 화면 우상단에 **전체 화면 버튼**이 있어요. 지원하는 기기에서는 전체 화면과 함께 가로 고정도 시도해요.
- **가상 조이스틱**: 왼쪽 화면 절반 어디를 눌러도 그 자리에 조이스틱이 생겨요 (떠다니는 방식).
- **버튼**: 점프 버튼은 지름 약 80픽셀로 크게, 대시 버튼은 약 60픽셀. 설정에서 크기와 투명도 조절 가능.
- 버튼을 누르면 짧은 **진동 피드백** (지원 기기만).
- 배치 단계에서는 아이템을 **손가락으로 끌어서** 놓고, 손가락에 가려지지 않도록 아이템이 손가락보다 살짝 위에 표시돼요.
- 두 손가락으로 **확대/축소**해서 맵을 볼 수 있어요.
- 아이폰 노치 같은 안전 영역을 피해서 버튼을 배치해요.

## 14. 성능 최적화

- **캔버스 2D 렌더링**: 내부 해상도가 작아서 저사양 폰에서도 가벼워요.
- **고정 프레임 물리**: 물리는 초당 60번 일정하게 계산하고, 화면 주사율(60/120Hz)과 상관없이 똑같이 움직여요.
- 움직이지 않는 지형은 **미리 한 장의 그림으로 그려 두고** 재사용해요. 블록이 놓이거나 지워질 때만 해당 부분을 다시 그려요.
- 스프라이트는 시작할 때 한 번만 생성해서 **한 장의 큰 이미지(아틀라스)**에 모아 둬요.
- 파티클, 화살 같은 자주 생기고 사라지는 객체는 **재사용 풀**로 관리해서 끊김을 막아요.
- 화면 밖에 있는 함정은 그리지 않아요.
- 탭을 벗어나거나 앱을 내리면 자동으로 일시정지(혼자 하기)하거나 렌더링을 멈춰요(온라인).
- 목표: 보급형 폰에서도 **60fps 유지**, 첫 로딩 **2초 이내**, 전체 용량 **500KB 이하**(글꼴 제외).

## 15. 소스 보호

- **우클릭 메뉴, 텍스트 선택, 드래그 차단**
- **단축키 차단**: F12, Ctrl+Shift+I/J/C, Ctrl+U, Ctrl+S (맥은 Cmd 조합 포함)
- **개발자 도구 열림 감지**: 감지되면 게임 화면을 가리고 경고를 띄워요
- **코드 난독화**: 배포용 코드는 javascript-obfuscator로 변수명 치환, 문자열 암호화, 제어 흐름 뒤섞기, 디버거 방해를 적용해요
- **원본 코드 보관**: 원본 코드(`src/`)는 같은 저장소에 함께 보관하고, 수정할 때는 원본을 고친 뒤 다시 난독화해서 배포해요
- ⚠️ 원본이 공개 저장소에 있으므로 GitHub 저장소 페이지에서는 원본 코드를 누구나 볼 수 있어요. 난독화와 차단은 **게임 사이트에서 코드를 보는 것**만 어렵게 해요. (사용자 결정 사항)

> ⚠️ 솔직하게 말씀드리면, 웹 게임은 브라우저에서 실행되는 이상 **완벽하게 막는 것은 불가능**해요. 위 조치들은 일반 사용자나 초보자가 코드를 보거나 베끼는 것을 **충분히 어렵게 만드는** 수준이에요.

## 18. 결정된 사항 기록

- 원본 코드는 같은 저장소의 `src/`에 함께 보관해요.
- 함정 처치 보너스는 골인 여부와 상관없이 항상 받아요.
- 전원 골인(너무 쉬움)일 때만 전원 0점이에요. 전원 실패는 벌칙 없이 처치 보너스가 인정돼요.

- 텔레포터는 삭제했어요 (v1.1).
- 배경음악은 직접 합성한 칩튠 대신, 사용자가 제공한 MP3 한 곡(`audio/bgm.mp3`)을 모든 화면에서 반복 재생해요 (v1.1).

## v1.3 변경 사항
- 기본 지형 발판을 크게 줄였어요. 구덩이가 넓어져서 정확한 점프나 대시가 필요하고, 플레이어가 놓는 블록이 더 중요해졌어요.
- 봇은 이제 실제 최적 경로(길찾기 결과)를 따라 함정을 놓아서, 놓인 함정이 진짜 길목을 노려요. 전원 골인한 라운드 다음에는 경로를 다시 분석해요.
- 버그 수정: 배치 단계에서 ↑/W로 커서를 움직이면 바로 놓아지던 문제, 상자 단계에서 누른 키 때문에 배치가 시작되자마자 자동으로 놓아지던 문제를 고쳤어요. 배치는 클릭 · Enter · 스페이스(모바일은 [놓기])로만 확정돼요.

## v1.5 변경 사항
- 점프 높이 3.5칸 → 약 2.7칸, 벽 점프도 같은 비율로 낮춤.
- 대시 3칸 → 약 2.2칸, 위쪽 대시는 70% 세기. (점프 + 위쪽 대시 최대 높이 5칸 → 약 3.8칸, 점프 + 대시 최대 거리 8.3칸 → 약 6.8칸)

- 버그 수정: 쿵쿵이·프레스가 쉬고 있을 때 머리만 공중에 떠 보이던 문제 (몸통이 머리를 덮도록 그리는 순서 수정).
